# Russian language

Always communicate with the user in Russian.

Rules:

- Always answer the user in Russian.
- Do not switch to English unless the user explicitly asks for English.
- Explanations, conclusions, questions and descriptions must be in Russian.
- Keep source code, commands, filenames, class names, API names, Git commands, error messages and technical identifiers unchanged.
- English output from tools may be quoted when necessary, but explanations must be in Russian.
